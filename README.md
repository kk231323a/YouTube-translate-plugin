# YouTube-translate plugin

一个面向 YouTube 的 Chrome 字幕翻译扩展。它优先读取视频的原语言字幕并翻译成中文；对完全没有字幕的英文视频，可使用本地 Whisper 进行语音识别。

## 功能

- 优先使用原语言字幕，避免中文内容被转换成英文。
- 优先调用 Chrome 内置离线翻译，减少网络延迟。
- 自动捕获 YouTube 播放器加载的完整字幕轨并提前翻译后续字幕。
- 英文视频没有字幕时，可捕获当前标签页音频并在本地识别。
- 支持简体中文、繁体中文、字幕字号和背景浓度设置。
- 语音识别音频不上传；Chrome 翻译语言包和 Whisper 模型仅首次下载。

## 环境要求

- Google Chrome 或 Chromium 138 及以上。
- 无字幕语音识别需要支持 WebAssembly 的桌面浏览器。

## 安装

1. 从 [Releases](https://github.com/kk231323a/YouTube-translate-plugin/releases) 下载最新 ZIP。
2. 解压 ZIP 到固定目录。
3. 打开 `chrome://extensions`。
4. 开启右上角“开发者模式”。
5. 点击“加载未打包的扩展程序”，选择解压后的目录。
6. 打开 YouTube 视频页并按需在扩展弹窗中启用设置。

如果安装或更新扩展时 YouTube 页面已经打开，重新加载扩展后会尝试自动补注入内容脚本；仍无效果时刷新一次 YouTube 页面。

## 无字幕视频

1. 打开英文 YouTube 视频。
2. 点击扩展图标。
3. 点击“开始本地语音识别”。
4. 首次使用会下载翻译语言包和 Whisper Tiny 模型。

Chrome 要求用户真实点击扩展后才能捕获标签页音频；这是浏览器安全限制。

## 隐私

- 无字幕识别在当前浏览器内运行，音频不会上传到远程语音识别服务。
- 普通字幕翻译优先使用 Chrome 内置翻译。
- 若本机不支持内置翻译，扩展可能回退到 Google 翻译或 YouTube 自带中文译轨。

## 当前限制

- 字幕和翻译表现取决于视频提供的字幕轨、YouTube 页面结构及 Chrome 翻译语言包。
- 无字幕识别速度取决于电脑性能。
- 自动翻译无法达到人工字幕的准确度。
